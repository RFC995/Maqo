# Fotos dos dispositivos

Coloca aqui as fotos reais dos produtos, em PNG, com o nome exato do modelo:

```
public/devices/AM319.png
public/devices/UG65.png
public/devices/EM300-TH.png
```

A aplicacao procura `/devices/<MODELO>.png` automaticamente. Se o ficheiro nao
existir, e usado o desenho vetorial de substituicao (que ja reproduz a forma
real de cada familia de produto). Nao e preciso registar nada em codigo.

Fundo transparente e um recorte quadrado dao o melhor resultado.
